# BibliotecaPessoal
Bibliotheca Athenae 

✧ A Bibliotheca Athenae é uma biblioteca pessoal digital desenvolvida com o proposito de auxiliar leitores na organização de seus livros, no planejamento de leituras e 
no acompanhamento de suas atividades literárias.

✧ O projeto foi desenvolvido utilizando HTML, CSS e JavaScript.

✧ Identidade visual

✧ A identidade visual foi inspirada em bibliotecas clássicas, na estética Dark Academia e em Atena, deusa grega associada à sabedoria e ao conhecimento.

Paleta de cores:
✧Verde-escuro
✧Verde-oliva
✧Vinho
✧Marfim
✧Dourado envelhecido
✧Ébano

Funcionalidades:
✧Página inicial com resumo da biblioteca.
✧Carrossel horizontal de livros.
✧Cadastro de livros.
✧Organização por status de leitura.
✧Filtros para localizar livros.
✧Planejamento de leituras.
✧Diário literário.
✧Página de login demonstrativa.
✧Painel de acessibilidade.
✧Recursos de acessibilidade
✧Modo claro.
✧Modo escuro.
✧Aumento e diminuição da fonte.
✧Alto contraste.
✧Interface responsiva.

✧ Tecnologias utilizadas

HTML: estruturação das páginas.
CSS3: estilização e responsividade.
JavaScript: funcionalidades e interatividade.

Bootstrap: framework CSS.

✧ Como executar o projeto
Clone o repositório:

git clone LINK_DO_REPOSITORIO

Abra a pasta do projeto no Visual Studio Code.

Execute o arquivo index.html utilizando a extensão Live Server.

O site será aberto no navegador.

✧ Acessibilidade e usabilidade

O projeto considera princípios das WCAG e as heurísticas de usabilidade de Nielsen, buscando oferecer uma interface organizada, compreensível e acessível.

✧ Projeto acadêmico desenvolvido para a disciplina de Desenvolvimento de Interface.
